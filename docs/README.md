# Documentation

The operator documentation is the [blackhole-threats docs site](https://netspeedy.github.io/blackhole-threats/), built from
[`website/`](../website/README.md). The other files in this folder are pointers to it, kept so
old links still land somewhere, apart from
[release-and-publishing.md](release-and-publishing.md), which is for maintainers.

## On the site

| Page | Use it for |
| --- | --- |
| [Quickstart](https://netspeedy.github.io/blackhole-threats/quickstart/) | A source build and a first refresh against a local feed |
| [Installation](https://netspeedy.github.io/blackhole-threats/installation/) | The APT repository, the container image, release archives and source builds |
| [How it works](https://netspeedy.github.io/blackhole-threats/how-it-works/) | Startup, the refresh loop, feeds, communities and BGP announcements |
| [Guides](https://netspeedy.github.io/blackhole-threats/guides/configuration/) | Configuration, the Debian package, the container, router policy, operations and troubleshooting |
| [Reference](https://netspeedy.github.io/blackhole-threats/reference/cli/) | Flags, config keys, feed formats, log messages, signals, exit codes and paths |
